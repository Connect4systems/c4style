# Video reference review

Reference: [ERPNext Custom Theme by Kanak Infosystems](https://www.youtube.com/watch?v=B_0SsIDih1k), plus the enlarged Item-list screenshot supplied in chat.

This review uses visual storyboard samples at five-second intervals across the 14:46 walkthrough. Audio/captions were unavailable. Times below are approximate; this is a feature comparison, not a claim that every vendor option has been reproduced.

| Visible behavior | Approximate time | C4Style implementation |
| --- | --- | --- |
| Narrow branded icon rail | 0:10 onward | Persistent permitted-workspace menu with the existing app logo and personal width preference. |
| Rounded inset header and centered search | Throughout | Capsule or flat header; native search and breadcrumbs remain functional. |
| Announcement above header | Throughout; configured around 10:30–11:30 | Manager-controlled plain-text ticker, speed and colors; dismissible per page session, with reduced-motion support. |
| Palette chooser | Around 1:05–1:20 | Appearance tools palette picker with 17 coordinated palettes and confirmation before changing the shared theme. |
| Colored headers, filter inputs and action buttons | Around 2:00–4:30; supplied screenshot | Separate rounded rows, hover borders, taupe actions, configurable input borders, boxed/underline fields, filled/outline buttons and shadows. |
| Grouping list sections | Around 3:00–4:30 | Group loaded rows by available list columns; expand/collapse groups without cloning records or replacing data queries. |
| Notification and user drawers | Around 4:25–5:05 | Native dropdown content presented in side drawers; close button, backdrop and Escape dismissal. |
| Hover-expanded menu | Around 5:05 | Hover/focus expansion without changing the saved width preference. |

| RTL layout | Around 13:30–14:30 | Site default and personal direction switch; menu placement and arrows follow the chosen direction. |

## Differences and limits

- Shared styling is editable only by System Manager or Website Manager, as requested. Normal users control their own menu width, workspace width, direction and notes.
- Settings remain a native Single DocType rather than separate vendor Themes records.
- Group counts cover loaded rows only; this is not server-wide aggregation or a pivot report.
- Palette colors are independent approximations. Vendor code and branding are not included.
- Vendor-specific loading animations have not been reproduced. Note text/colors persist per account; pin visibility and window positions last for the page session.
- Native filters, saved filters, sorting, view selection, bulk actions and record permissions retain their Frappe behavior.

## Validation

Browser tests cover component styling, menus, RTL placement, mobile overflow, palette confirmation, launcher filtering, announcement escaping/dismissal, note saving, loaded-row grouping, drawer closing and scrolling. Backend tests cover roles, validated settings, note limits and account-specific persistence.

The image at `artifacts/reference-layout-preview.png` is a synthetic browser fixture generated by `python -B tests/render_reference_preview.py`, using real app assets and sample data. It is not a screenshot of the deployed server. Migration, layout and native Bootstrap behavior still require verification on the target Frappe installation.
